# @ts-ha/core

The TypeScript Home Automation engine: automations, services, device sources,
the HTTP server, MQTT, state, scheduling, and Zigbee2MQTT integration. It
re-exports the shared contracts so its public surface is stable.

Depends on `@ts-ha/shared` only — it has no knowledge of the web UI.

Part of the [TypeScript Home Automation](https://github.com/Supporterino/TypeScript-Home-Automation)
workspace. Licensed under GPL-3.0-only.
