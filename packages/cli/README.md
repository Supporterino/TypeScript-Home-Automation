# @ts-ha/cli

The TypeScript Home Automation command-line interface and OpenTUI terminal
dashboard. Provides the `ts-ha` binary, including `ts-ha run` to boot a local
engine.

Depends on `@ts-ha/core` and `@ts-ha/shared`; the web UI is loaded as an
optional peer when enabled.

Part of the [TypeScript Home Automation](https://github.com/Supporterino/TypeScript-Home-Automation)
workspace. Licensed under GPL-3.0-only.
